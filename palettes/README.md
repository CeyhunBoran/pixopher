# Built-in palettes

Each `.pxo` file here holds one built-in palette: its entries in order and
its suggested ramps. They are embedded in the binary, and `pxo new
--palette <name>` copies one into a new document.

| Name | Colors | Source |
| --- | --- | --- |
| `default` | 16 | The colors of Sweetie 16 by GrafxKid, <http://grafxkid.tumblr.com/palettes>, listed at <https://lospec.com/palette-list/sweetie-16>, with one-letter keys that recall their names (`o` ink, `r` red, `w` white, ...). New documents start with it. |

It has the ramps `warm` (plum to yellow, base coral), `green`, `blue`
and `gray` (ink to white).
